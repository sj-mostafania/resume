خلاصهٔ حرفه‌ای

توسعه‌دهنده فرانت‌اند با بیش از ۱۲ سال تجربه در توسعه نرم‌افزار و سابقهٔ گسترده در ساخت اپلیکیشن‌های سازمانی در حوزهٔ بانکداری و مالی. با تسلط بر JavaScript، TypeScript، React و Angular، معماری فرانت‌اند، توسعهٔ کامپوننت‌های قابل استفاده مجدد، مدیریت State، بهینه‌سازی عملکرد و اپلیکیشن‌های داده‌محور در مقیاس بزرگ. دارای تجربه در طراحی معماری‌های نگهداشت‌پذیر، سیستم‌های UI قابل استفاده مجدد و راهکارهای DataGrid سمت سرور و همکاری نزدیک با لایه‌های API و پایگاه داده. تجربهٔ پیشین با Angular و اپلیکیشن‌های سازمانی .NET، درکی عمیق از اپلیکیشن‌های تجاری در مقیاس بزرگ و معماری سرتاسری سیستم فراهم می‌کند.

مهارت‌های اصلی فرانت‌اند

JavaScript / TypeScript React 16 / 18 Angular Redux Zustand React Query RxJS (اکوسیستم Angular) MUI HTML5 / CSS3 SASS / SCSS اتصال به REST API RTL / UI فارسی بین‌المللی‌سازی (i18n) کامپوننت‌های قابل استفاده مجدد معماری فرانت‌اند مدیریت State بهینه‌سازی عملکرد دسترس‌پذیری (Accessibility)
